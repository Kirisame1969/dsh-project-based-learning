# 轻量领域导航规范

领域导航只帮助 AI 避免路线失序，不储存课程正文。即使没有任何领域导航，也应能使用通用教学循环完成教学。

## 单个导航应包含

- 领域覆盖范围和典型作品；
- 粗略阶段与关键依赖；
- 少数不能轻易跳过的门槛概念；
- 常见误区、安全风险和版本敏感点；
- 必要时建议优先查阅的官方资料类型。

## 单个导航不得包含

- 诊断题库、答案或固定测验；
- 逐课讲稿、固定课时和完整课程树；
- 预制练习清单、任务卡或验收量表；
- 为每个概念准备的固定示例代码；
- 穷举式术语表。

保持单文件、粗粒度。只有当内容因工具版本或子领域差异而明显无关时，才新增另一份导航。

## 生成本次教学内容

读取导航后，根据以下信息即时生成本次讲解与实践：

1. 用户当前作品和想看到的效果；
2. 对话与状态中已经展示的理解；
3. 实际项目、工具版本和资产；
4. 导航中的依赖与风险；
5. 本次能够完成的一个可观察结果。

可以跳过、合并、回退或改序。不要因为导航列出了某阶段，就强迫学习者完成全部前置课时。

即时生成的讲解应符合教学循环：必要知识先讲、示例可运行、新知识就地解释、练习与当前作品相连、预期现象明确。不要生成一套与用户项目无关的通用题库。

一次性生成的题目、示例和讲解不写回导航。只有长期有效的路线依赖、稳定风险或版本边界才值得维护到导航中。
